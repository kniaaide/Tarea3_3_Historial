# Tarea3_3_Historial

Aplicación académica en C# que modela un **navegador con historial de navegación**.

## Contenido

La solución incluye una pila dinámica, nodos y la clase `NavegadorHistorial` para gestionar el historial. La interfaz gráfica permite interactuar con la aplicación; `CasosDePrueba.cs` reúne casos para probar el comportamiento.

## Requisitos

- Visual Studio con soporte para C# y Windows Forms.
- .NET compatible con `Tarea3_3_Historial.csproj`.

## Ejecución

Abre `Tarea3_3_Historial.sln` en Visual Studio y ejecuta el proyecto.

## Propósito

Aplicar el uso de pilas dinámicas a una funcionalidad cotidiana: recorrer el historial de navegación.
